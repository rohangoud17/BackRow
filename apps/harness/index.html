Session

Every tab in this browser shares one voter identity, so a second tab can't act as a second student. Use the button above (or an incognito window) to simulate someone new.
Reconnect is automatic with jittered backoff, the heartbeat fires every 4.5 min, and the socket rotates at 1h50m before API Gateway's 2-hour cap. Kill your wifi briefly to watch it recover and re-join.

Reactions

Reactions aren't relayed one by one — that would be taps × members pushes per second. Each tap increments a sharded counter, and one invocation per second wins a conditional write and broadcasts the room's cumulative totals, so fan-out is bounded by time rather than by how hard people are tapping. Totals are cumulative rather than deltas, so a dropped frame corrects itself; your client animates the difference from the last totals it saw, capped at 12.

Send

Event log

Heartbeat RTT is a true round trip measured on one clock, so it's always trustworthy. Delivery is one-way, and sentAt is stamped by the server's clock — so the raw subtraction measures latency plus the offset between your machine's clock and AWS's, which is routinely over a second. It's corrected here using an NTP-style estimate from the ping/pong round trip, and shows nothing until at least one pong has calibrated it, because a wrong number is worse than no number. The raw value is logged in brackets alongside so you can see the difference.
